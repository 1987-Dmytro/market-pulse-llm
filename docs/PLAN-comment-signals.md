# Машинерия сигналов из комментариев — драфт тимлида 15.08, на дизайн-сидение

> Целевой результат зафиксирован оператором: ручной разбор тредов окна-1
> (сообщение тимлида 15.08 — «День морозива», Ласунка, творог-пицца и т.д.)
> — это ОБРАЗЕЦ выхода системы. Задача: воспроизводить его машиной на каждом
> окне. Файл тимлида; финальные слова таксономии — оператора, на сидении.

## 1. Что именно делал тимлид руками (декомпозиция — она и есть конвейер)

1. Собрал ТРЕДЫ: пост + все его комментарии (машинно: у нас есть parent_msg_id).
2. Отобрал кандидатов ЛЕКСИКОНОМ: бренды ∪ категории (машинно, $0).
3. Выкинул ШУМ ПО ПРАВИЛАМ: «варто»-слово, гивевей-треды, «+»/«Тест»-спам,
   скам-боты (машинно: 4 дешёвых глушителя, ниже).
4. ПРОЧЁЛ каждый оставшийся тред целиком в контексте и решил: кто субъект
   (бренд / сеть / категория-личное / не наш рынок), какое отношение, какой
   аспект, что здесь СИГНАЛ для директора, какая цитата — доказательство.
   ← единственная интеллектуальная ступень. Это и есть LLM-задача.
5. Сложил СВОДКУ: сигналы с цитатами и источниками, по классам.
   (машинно: агрегация + экран «Сигналы окна».)

## 2. Конвейер (пять ступеней)

**A. Треды** ($0, скрипты): пост + комменты по parent_msg_id.
**B. Гейт** ($0, скрипты): лексикон брендов∪категорий по всему треду. Четыре
глушителя ДО оплаты: (1) «варто»-класс — хит только с маркером (рулинг
10.08); (2) треды giveaway-постов — вне бренд-анализа (тип поста уже
размечает модель, гейт G1d 0.96); (3) плюс-спам — правило длины/повторов
(«+», «Тест» ×N); (4) скам-паттерн (деньги+хендл/ссылка). Что глушители
убили — считается бесплатным счётчиком, LLM этого не видит.
**C. LLM-чтение треда** (платно, ~12–15 тредов на окно): ОДИН вызов на тред,
полный контекст, рамка задачи = 7 вопросов директора из PRODUCT.md
(«сигнал = то, что отвечает на один из вопросов»). Выход — JSON по схеме §3.
**D. Агрегация** ($0): сигналы и по-комментные привязки → SQLite → экран
«Сигналы окна» (карточки: тред → суммаризация → размеченные цитаты) +
разрезы по subject_type. Бренд-экраны питаются ТОЛЬКО привязками LLM.
**E. Верификация**: каждый сигнал несёт evidence-msg_id (дрилл-даун до
оригинала — наш паттерн); машина меряется против референса (§5).

## 3. Схема вердикта треда (черновик — слова финализирует оператор)

```json
{
  "thread": {"channel": "...", "post_id": 10613},
  "post_summary": "промо Дня морозива: Лімо/Рудь/Три Ведмеді/Хрещатик",
  "discussion_summary": "спрос на без цукру; жалоба на перемороженное с
      возвратами; похвала вкусу; спор о заангажированности",
  "signals": [
    {"signal_type": "жалоба", "subject_type": "сеть",
     "subject_id": "varus", "aspect": "качество",
     "stance": "negative",
     "reading": "холодовая цепь: мороженое перемерзшее, возвраты не у одного",
     "evidence": [21626], "quote": "з нього просто тече вода…"},
    {"signal_type": "спрос", "subject_type": "категория",
     "subject_id": "морозиво_без_цукру", "aspect": "наличие",
     "evidence": [21599, 21601]}
  ],
  "per_comment": [
    {"msg_id": 21626, "subject_type": "сеть", "subject_id": "varus",
     "stance": "negative", "aspects": ["качество"]},
    {"msg_id": 580129, "subject_type": "категория_личное",
     "subject_id": null, "stance": null,
     "note": "не любит мороженое вообще — не бренд-отношение"}
  ],
  "noise": [{"msg_id": 20765, "class": "plus_spam"}]
}
```

Классы subject_type: **молочный_бренд · сеть_ритейлер · категория_личное ·
не_наш_рынок** (Гармонія-центр). Классы signal_type: **спрос · жалоба ·
похвала · привычка · тренд** (открытый список — слово оператора).
Существующие головы модели (тональность/сарказм/интенты по строке) НЕ
отменяются — стенс-слой ДОБАВЛЯЕТ субъекта и сигналы; расхождения двух
слоёв — отдельная колонка честности, не тихая перезапись.

## 4. Чем машина лучше ручного разбора — и чем хуже, честно

Лучше: каждое окно за минуты; evidence-ссылки на каждый вывод; сравнимость
окон между собой; человекочитаемый объём (оператор МОЖЕТ проверить глазами
всё окно — 12–15 карточек). Хуже: точность чтения НЕ доказана — поэтому
проба и прережка, никогда «поверили на слово». Референс уже существует:
ручной разбор тимлида по окну-1.

## 5. Гейты качества (прережка пробы — бары словом оператора ДО запуска)

1. **Signal recall против референса:** флагманские сигналы окна-1 (холодовая
   цепь VARUS, спрос на без-сахара, Ласунка-availability, творог-АТБ-привычка,
   протеиновый тренд) машина ОБЯЗАНА найти.
2. **Per-comment согласие** по subject_type и stance против адъюдицированного
   голда (мой разбор → сидение оператора → голд v1).
3. **Noise precision:** ноль сигналов из плюс-спама/скама/гивевеев.
Одна попытка; провал закрывает вопрос разбором дизайна, не тихим ретраем.

## 6. Цена (порядок; точные числа даст ценз fix-a и сама проба)

Гейт и глушители — $0. LLM-чтение: ~12–15 тредов на окно одним вызовом
каждый — копейки на замеренных ценах serverless; проба на ВСЕХ кандидатах
окна-1 — в пределах ≤$0.20 (правило ручной пробы 12.08). Против $5.31,
заплаченных за сплошную разметку окна-1, — порядок экономии виден без
калькулятора; точную проекцию несёт контракт.

## 7. Дорожка (контракты)

fix-a ($0: глушители гейта + честные подписи экранов + полный ценз с
вариантами гейта + промо-таблица T5) → **дизайн-сидение** (таксономия §3
твоим словом; промпт; бары §5; ~30–40 мин) → **проба** на тредах окна-1
против референса → адъюдикация → прережка → закон цикла-2 (амендмент) +
экран «Сигналы окна» в 6c. Референс-пак: мой разбор 15.08 оформляется
структурированным голдом НА сидении (не задним числом после пробы).
