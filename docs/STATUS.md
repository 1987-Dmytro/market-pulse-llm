## Что это за проект (одним абзацем)

Ключевой инструмент маркетинговых исследований компании (ТМ «Гармонія»):
мониторим Telegram-каналы украинских ритейл-сетей (Сільпо, АТБ, Varus,
Маркетопт) и агрегаторов, находим анонсы новинок и промо по молочке/мороженому,
извлекаем бренды и позиции с ценами, классифицируем реакции покупателей
(тональность, сарказм, скрытые интенции), и превращаем это в командный центр
директора по маркетингу. Ядро — открытая LLM (Gemma-4-31B), дообученная QLoRA;
GPU только арендные, между сессиями консоль пуста. Северная звезда — семь
вопросов директора в `docs/PRODUCT.md`.

## Правила, которые легко забыть

- Все eval гейтов — батчом 1; v2/v4-голды и запечатанные вердикты неизменны.
- Числа — только из result-файлов через скорер; в презентационные артефакты
  руками не вписываются (закон 3.20, отравленный тест).
- **Деньги читаются из гарда, не из леджера и не из прозы** (Dv33); у шагового
  чтения пока нет верхней границы окна — чинится контрактом «--until».
- **Прережка замерзает при первом `pod create` попытки**; правка после —
  только новой регистрацией; кап живёт в регистрации, его поднятие — слово
  оператора ДО эндпоинта.
- **Пины — потребители:** `prompts.py`, `brands.py`, `local_llm.py`,
  `window_summary_5c2.py`, PLAN-файлы пинуются запечатанными записями; правка
  требует MOVED-манёвра, не перепина. Префлайт любого контракта: греп пинов
  на всё, что он трогает (с «--until» — через preflight-инструмент H1).
- `registry.yaml` и `lexicon.yaml` запечатаны — правила матчинга в
  `config/watchlist_rules.yaml`; правки только новыми ревизиями.
- Никогда `git add -A`; файлы тимлида исполнитель коммитит, не правит;
  отчёты — файлами в `docs/reports/`, в чат — только путь.
- Впрыснутые треды проб (`injected: true`) никогда не входят в
  продакшн-агрегаты и цену окна.
- Пре-регистрации не переоткрываются; провал закрывает вопрос (one attempt);
  сработавший stop-rule закрывает ЛИНИЮ, не попытку.
