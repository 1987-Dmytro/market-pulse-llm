## Что это за проект (одним абзацем)

Ключевой инструмент маркетинговых исследований компании (ТМ «Гармонія»):
мониторим Telegram-каналы украинских ритейл-сетей (Сільпо, АТБ, Varus) и
агрегаторов, находим анонсы новинок и промо по молочке/мороженому, извлекаем
бренды, классифицируем реакции покупателей (тональность, сарказм, скрытые
интенции: вкус/цена/упаковка/качество/наличие). Ядро — одна открытая LLM,
дообученная QLoRA на арендованной GPU. MVP: только Telegram, $0 за данные.

  (гейт был ≥5 000 комментов — пройден с запасом ×2.3).
- Разметка: 2 000 комментов + 1 000 постов (LLM + операторская калибровка,
  agreement 96.3% / 100% при пороге 90%).
- Заморожено с SHA256: тест комментов 400 строк (v2, 52 сарказма), тест
  постов 250, sarcasm-holdout 108, трейн-источники ~2 350 скорируемых.
- Верификатор: make check, 108 тестов, зелёный после каждого коммита.

## Ключевые решения (и почему)

1. Telegram-only MVP — решение оператора (легально, бесплатно; FB/IG/X
   исследованы и отложены в трек R с ценами).
2. Ритейл-сети вместо производителей — решение оператора (производители не
   ведут TG; у сетей живые каналы).
3. EN исключён из гейтов (поправка 3.1) — в корпусе 8 EN-строк из 2 000.
4. Sarcasm-holdout 108 строк вместо 150–200 (поправка 3.2) — корпус
   физически исчерпан; честно записан fallback на малое n.

## Решения ревизии подхода (2026-07-28)

- Совместный протокол: ни один промт в Claude Code без обсуждения шага
  (брифинг → вопросы обеих сторон → решение). Вшито в скилл team-lead.
- Постоянное делегирование: чисто механические фиксы (опечатки, даты,
  формат) идут без обсуждения, но всегда видны в отчёте исполнителя.
- ADR — на английском в knowledge/decisions/; русские выжимки решений —
  здесь, в STATUS.md.
- Residual-лик холдаута (31 строка делит треды с обучающим пулом): принят
  с обоснованием (модель видит только текст коммента), компенсируется
  расширением сарказм-данных для ОБУЧЕНИЯ (источник обсуждается).
