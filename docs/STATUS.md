## Что это за проект (одним абзацем)

Инструмент маркетинговых исследований ТМ «Гармонія» (`docs/PRODUCT.md` — семь вопросов директора):
мониторинг Telegram-каналов украинского ритейла, разметка реакций покупателей (тональность, сарказм,
скрытые интенции, бренды) дообученной открытой LLM (Gemma-4-31B + QLoRA-адаптер 4.5h2), агрегаты →
командный центр. Вторая цель — витрина навыков дообучения (LinkedIn): «база ошибается на сарказме,
дообученная — нет», с честными числами и хроникой. GPU только арендные; между сессиями консоль пуста.

## Правила, которые легко забыть

- Числа — только из result-файлов через скорер/билд; в README и дашборд руками не вписываются
  (закон 3.20). Каждое число в отчёте называет файл, откуда взято.
- Деньги — из гарда (Dv33); часы пода — число для цитаты; walk отстаёт. Платный под не оставляют
  без опроса; кап — 2× оценки из реестра; перерасход ≤20% → ASK-рунг, не KILL.
- Пре-регистрации не переоткрываются; провал закрывает вопрос; stop-rule закрывает ЛИНИЮ.
- Файлы тимлида (STATUS/SPEC/PROMPT-*/`docs/labels-pass1-r1.jsonl`/`docs/reviews/`) исполнитель
  коммитит, не правит. Никогда `git add -A`. `make fmt` репо-целиком запрещён (пин продюсера).
- Пины — потребители: `prompts.py`, `scorer.py`, `brands.py`, `local_llm.py`, `window_summary_5c2.py`,
  PLAN-файлы; `registry.yaml`/`lexicon.yaml` запечатаны — правки новыми ревизиями. `make preflight`
  перед контрактом, трогающим пины.
- Новый гейт/тест/рунг называет потерю, которую предотвращает; контракт — пункт DoD; иначе не выдаётся.
- Отчёт — файл в `docs/reports/`, в чат — только путь; приёмка фичи — в тот же день.
