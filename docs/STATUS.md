## Правила, которые легко забыть (механика — `docs/PROCESS.md`)

- Числа — только из result-файлов через скорер/билд, каждое называет файл (закон 3.20). Деньги — из
  гарда; час пода — число для цитаты, гард рядом; кап 2× оценки; перерасход ≤20% → ASK, не KILL.
- Пре-регистрации не переоткрываются; провал закрывает вопрос; stop-rule закрывает линию.
- Файлы тимлида исполнитель коммитит по пути, не правит. Никогда `git add -A`, никогда `make fmt` репо-целиком.
  Пины и запечатанные записи — `make preflight` до контракта, который их двигает.
- Новый гейт/тест/рунг называет потерю, которую предотвращает; контракт — пункт DoD; отчёт — файл в
  `docs/reports/`, в чат только путь; приёмка — в тот же день.
