## Правило чтения голда

По-комментный бар (≥0.80, рулинг 15.08) считается ТОЛЬКО по строкам,
явно названным в этом файле (msg-id выше). Расширение голда на остальные
строки — дело адъюдикационного сидения ПОСЛЕ прогона; оно меняет закон
слоя, но не оценку этой пробы. Никогда не перечитывать этот файл задним
числом под результат машины.
