> Черновик тимлида 15.08.2026, на утверждение оператора. По-русски намеренно

## 1. Замысел

Не «дашборд», а **командный центр** — по этике Mission Control из FlashArb
(один источник правды, вкладки по доменам, алерты и статусы на виду), но
статический: **HTML-файл, собираемый скриптом из result-файлов**, без
сервера. Три роли-читателя: директор по маркетингу, коммерческий директор,
собственник. Языки: **UA / EN переключателем** в одном файле.

Принципы (не обсуждаются, это законы проекта, теперь в коде):
- **Ни одного числа руками.** Билд-скрипт читает только артефакты;
  отсутствие источника роняет сборку громко. У каждого числа — провенанс
  (файл + поле), доступный из UI.
- **Каждая метрика несёт справку** ⓘ: определение UA/EN, как считается,
  как читать, типичные ловушки. Отдельная вкладка «Методология» — глоссарий
  и честные ограничения (гейты модели, размеры выборок).
- **Снимок называет своё окно.** Баннер «окно 4 недель, якорь 09.08»;
  одиночные цифры всегда рядом со своим агрегатом; тренды появляются
  только со вторым окном — и до того так и написано.
- **Drill-down до первоисточника:** клик по числу → строки «оригинал
  комментария рядом с разбором» (паттерн наших сидений 3.18 (6)) со
  ссылкой на t.me. Это главная фича доверия к системе.

## 3. Вкладки командного центра (v1 — девять)

**T0 · Обзор (экран собственника).** 5–6 KPI-карт по правилу «инвертированной
пирамиды»: объём реакций окна · чистая тональность (NSR) · доля негатива с
сарказм-поправкой · SoV Гармонії среди watchlist · медиана глубины скидки
сетей · покрытие (каналы/сегменты/подписчики). Каждая карта: значение,
сравнение (пока «окно-1 = база»), статус. Ниже — «3 вывода окна»
(генерируются кодом по правилам из чисел — развилка №3).

**T1 · Тональность и бренды (вопрос 1 PRODUCT.md).** Бренд × тональность
(Гармонія на фоне watchlist), SoV, сарказм-выправление показано явно
(бейдж «N издёвок переклассифицировано в негатив»). Drill-down до строк.

**T2 · Аспекты (вопрос 2).** Цена · вкус · качество · упаковка · наличие ·
сервис: доли, матрица бренд × аспект, «профиль негатива» (о чём именно
жалуются). Окно-1: цена 553 · вкус 245 · наличие 184 · сервис 161 ·
качество 138 · упаковка 17 — числа тянутся билдом, тут для масштаба.

**T3 · Сегменты аудитории (вопрос 5 + твоя группировка).** Восемь карточек
по audience из реестра: мамы и дети · рецепты · ЗОЖ · регион (Полтавщина) ·
скидки-агрегаторы · официальные каналы сетей · детское питание ·
качество/госконтроль. В карточке: объём, тональность, топ-аспекты,
топ-бренды, каналы-источники со ссылками. «Мамы думают X, регион — Y» —
ровно рулинг 08.08, теперь экраном.

**T4 · Конкуренты (вопрос 3).** Таблица watchlist-брендов: SoV, NSR,
Δ против Гармонії, аспектный профиль, сегменты присутствия; private label
сетей помечены. Сортировки; drill-down.

**T5 · Промо и цены (вопрос 7 — экран коммерческого директора).** Из слоя
позиций: глубина скидки по брендам (медиана/разброс), промо-давление
(частота бренда в листовках), ярусы позиций R1–R5; цены из комментариев —
отдельным происхождением (в аспект «цена», в промо-агрегаты никогда —
закон 3.17). Баннер честности: «листовки АТБ-only (факт коллекции цикла-1);
Сільпо/Varus/Маркетопт собираются» — снимется после prep-b и окна-2.
**Промо Маркетопт обязательны в T5** (@marketopt_promo, куст Маркетопт,
Кременчук — домашний регион Гармонії) — рулинг оператора 15.08.

**T6 · Категории продукции (вопрос 4).** Честная заглушка со статусом:
таксономия 13+2 показана как справка, слой включается фазой 5c3
(категория = свойство поста, наследуется комментами). Никаких псевдо-чисел.

**T7 · Алерты (вопрос 6).** Дизайн-превью слоя: правило = «доля тональности
бренда отклонилась от его базовой линии на ±X пп за окно» (пороги — твоим
словом на дизайне алертов), доставка — Telegram оператору, обе полярности,
все бренды watchlist. Статус: «активируется окном-2» (базовой линии из
одного окна не бывает). Экран показывает, КАК это будет выглядеть.

**T8 · Методология и справка.** Глоссарий метрик UA/EN; как построена
система (модель, гейты 3/5 с числами и потолками — честность как фича);
окно и популяции; провенанс-манифест «какой экран ← какой файл»;
ограничения (сарказм-гейт 23/38, категории ждут 5c3, охват ≠ подписчики).

## 4. Словарь метрик (каждая — со справкой ⓘ в UI)

Ядро (по практикам social listening / brand health 2026): **Volume**
(объём упоминаний/реакций) · **NSR** (net sentiment rate = (поз−нег)/все) ·
**Negative share, sarcasm-adjusted** (наша фирменная: доля негатива ПОСЛЕ
выправления сарказма) · **SoV** (share of voice бренда среди watchlist —
главный конкурентный бенчмарк) · **Aspect share** (структура причин) ·
**Промо-глубина** (медиана/квартили скидки, из промо+печатного %) ·
**Промо-давление** (частота бренда в листовках за окно) · **Покрытие**
(каналы/сегменты; подписчики ≠ охват — честная сноска). Бенчмарк-рамка
тройная: против себя (окно к окну), против конкурентов (SoV/NSR),
аспирационная (лидер категории) — включается по мере накопления окон.

## 5. Прогнозирование — честная лестница (что можем, когда)

1. **Окно-1 (сейчас):** только срез. Никаких «трендов» из одной точки.
2. **Окно-2+ (цикл-2):** тренды по всем метрикам; базовые линии алертов;
   промо-цикличность листовок (какие бренды сети качают волнами).
3. **Накопление окон:** сезонность категорий (мороженое!), раннее
   обнаружение всплесков (алерты), сдвиги SoV после кампаний.
4. **[ASSUMED] С данными продаж ТПК (решение собственника):** связка
   «негатив по аспекту → динамика продаж SKU», промо-эффект (глубина
   скидки конкурента → наши продажи), лид-индикаторы спроса из
   разговоров. Это отдельный трек со своим гейтом легальности/формата —
   в план не входит, но архитектура (SQLite-агрегаты по окнам) его ждёт.

## 6. Персоны — кому какой экран

- **Директор по маркетингу:** T1–T4 + T7 (алерты) — бренд, причины,
  сегменты, конкуренты.
- **Коммерческий директор:** T5 (промо-давление и глубина скидок сетей,
  цены конкурентов из листовок) + T4 + аспект «наличие» из T2.
- **Собственник:** T0 (пять чисел с контекстом за 10 секунд) + T7.
v1 — один файл со вкладками; персональные «стартовые экраны» — этап 6c.

## 7. Дизайн-язык (практики августа 2026, источники в §9)

Инвертированная пирамида (KPI-карты → тренды → таблицы), один экран без
скролла на 1920×1080, drill-down вместо новых чартов (3 уровня: KPI →
сегмент → строки с оригиналом). Семантический цвет только для статуса
(зелёный/красный), нейтральная палитра для данных; тёмная и светлая темы.
У каждого числа — контекст (сравнение, цель или тренд): «голое число
запрещено». Мобильная вёрстка (карты стеком, тач-таргеты 44px, KPI ≥24px).
«Last updated» + окно данных на каждой вкладке. Приёмочный тест — на
наименее техническом читателе: время-до-ответа ≤10 секунд на каждый из
7 вопросов PRODUCT.md (наш квиз-паттерн, теперь для UI). Чарты по вопросу:
линии для трендов, горизонтальные бары для сравнений, никаких 3D/пирогов.
