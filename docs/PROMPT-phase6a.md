  for the three legs (comments, post_text, leaflet positions) carrying: channel, audience segment

  the rows carry them, and for positions: tier, carrier, the depth fields as recorded.

## Deliverable 2 — deterministic export + convergence

`scripts/export_dashboard_data.py` → **`results/dashboard_data_w1.json`** (committed). This is the
dashboard's only fuel.

- **Convergence test (the gate of this contract):** every figure the export shares with
  `results/window_summary_5c2.json` must EQUAL it — tonality counts (4 144/661/270-class), intent
  counts, populations (5 075 / 3 714 / 1 361), discount-depth median — both sides READ from the
  artifacts in the test, never typed. A mismatch is a red gate, not a rounding note.
- **Determinism:** two consecutive exports are byte-identical (sorted keys, no timestamps in the
  body; provenance carries inputs + sha256s + producer sha, no wall-clock). Show the empty diff.
- **Sample discipline:** beside every rate or price in the export, name the sample it was measured
  on. The registrations-and-draws rule may not inject for an `export_*` filename — open
  `.claude/rules/registrations-and-draws.md` by hand and apply it.
- A metric that cannot be computed from the rows (e.g. anything needing window-2 or the 5c3
  category layer) appears as an explicit `NOT_COMPUTABLE` entry with its unlock condition — the
  dashboard renders honest stubs from these, never zeros.
